# PyO3 Python Bindings Integration Plan

## Goal
Add Python bindings via PyO3/maturin so Python consumers get type-safe proto message classes backed by the Rust prost types, with protobuf encode/decode and JSON serialization.

## Architecture

Follow the existing pattern: a **shell script** (`scripts/prost-to-pyo3.sh`) parses
the generated `src/gen/*.rs` files and emits PyO3 wrapper code — mirroring how
`scripts/prost-to-zod.sh` generates Zod schemas from the same source.

```
src/gen/*.rs  ──(prost-to-pyo3.sh)──▶  src/py_gen.rs    (PyO3 #[pyclass] wrappers)
                                   ──▶  python/terp_proto/_types.pyi  (type stubs)
```

## Steps

### 1. Cargo.toml — add PyO3 deps behind `python` feature
- Feature `python` = `["dep:pyo3", "dep:pythonize", "dep:serde_json"]`
- `pyo3 = { version = "0.24", features = ["extension-module"], optional = true }`
- `pythonize = { version = "0.24", optional = true }`
- `serde_json = { version = "1", optional = true }`
- Add `crate-type = ["cdylib", "rlib"]` to `[lib]`

### 2. src/lib.rs — include generated modules
- Currently empty. Add `#[path]` module declarations for all `src/gen/*.rs` files.
- Guard the PyO3 module behind `#[cfg(feature = "python")]`.

### 3. scripts/prost-to-pyo3.sh — generate PyO3 wrapper code
Parses `src/gen/*.rs` (same state machine approach as prost-to-zod.sh):
- For each `pub struct Foo { ... }` with `#[prost::Message]`:
  - Emit a `#[pyclass]` wrapper struct holding a `serde_json::Value` (dict-backed)
  - `#[pymethods]`: `__new__(**kwargs)`, field getters/setters, `to_dict()`, `from_dict()`,
    `encode()` → bytes, `decode(bytes)` → Self, `to_json()`, `from_json()`
- For each `pub enum Bar`:
  - Emit a Python-accessible enum via PyO3
- Register all classes in a `#[pymodule]` per package (e.g., `terp.clock.v1`)
- Output: `src/py_gen.rs`

### 4. src/py.rs — PyO3 module entrypoint
- `#[pymodule] fn terp_proto(m: &Bound<'_, PyModule>)`
- Registers all submodules generated by the script
- Exposes top-level helpers: `encode(type_url, dict)`, `decode(type_url, bytes)`

### 5. pyproject.toml — maturin build config
```toml
[build-system]
requires = ["maturin>=1.0,<2.0"]
build-backend = "maturin"

[project]
name = "terp-proto"
requires-python = ">=3.9"

[tool.maturin]
features = ["python"]
module-name = "terp_proto._native"
```

### 6. python/terp_proto/ — Python package
- `__init__.py` — re-exports from `_native` + generated types
- `_types.pyi` — generated type stubs for IDE support

### 7. justfile — new recipes
- `py-gen` — run `prost-to-pyo3.sh`
- `py-build` — `maturin build --features python`
- `py-dev` — `maturin develop --features python`
- `gen-all` updated to include `py-gen`
